# PA-06D Rounding and Rebalancing Rule Register

**Status:** Documentation prerequisite; unresolved rows require product-owner approval

**Parent contract:** [PA-06D Quantity Truth Contract](../architecture/pa-06d-quantity-truth-rounding-rebalancing-contract.md)

**UI contract:** [PA-06D Requirement and Allocation Workbenches](../ui/pa-06d-requirement-allocation-workbench-spec.md)

## 1. Reading this register

The three tables below form one register. Join them by Rule ID. “Legacy” describes reviewed OPS evidence, not an Atlas approval. “Recommended” is a proposed future disposition unless explicitly identified as an approved direction. Internal examples use a decimal point; operator display examples use Vietnamese decimal commas.

## 7. Exhaustive below-source legacy cases for the mandatory inputs

The current theoretical formula first ceilings to the step, then applies PostgreSQL whole-number rounding whenever the intermediate result is at least `2`. For the mandatory inputs, every below-source result is:

|       2.01 |  0.1 |                      2.1 |                         2 |      0.01 |
|       2.39 |  0.1 |                      2.4 |                         2 |      0.39 |
