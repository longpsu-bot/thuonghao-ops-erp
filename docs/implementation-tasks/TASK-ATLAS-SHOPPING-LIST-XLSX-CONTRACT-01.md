## Frozen product and architecture decisions

One workbook is a generated collection of 1–7 service dates; each date sheet binds to its own current authoritative Confirmed Need batch. It creates no weekly batch, Planning aggregate, lifecycle object or cross-date transaction. Export requires complete saved/current facts and blocks an unsaved local draft until `Lưu` or discard/reload. `_ATLAS_META` has six workbook-wide fields and one per-date batch/version/Need Generation source record. Rows carry only stable marker/line/revision/decision/date/School/Location/Ingredient/Unit/exact quantity evidence in F:O. The old exported reason and note baselines are removed.

Import works after browser restart without a session manifest: parse, read every daily batch fresh, validate every-and-only lines and currentness, compare exact quantity and publish only local Confirmed Need quantity proposals. A stale or wrong batch on any date rejects the whole workbook with no draft changes. Explicit `Lưu` remains the only backend write. `GHI CHÚ` initially prints the first active/effective preferred Supplier name and remains working paper; Atlas V1 never imports or persists it. Supplier drift alone does not stale a quantity row. Governed adjustment reason/explanation remains an Atlas Save requirement. Supplier allocation belongs to Procurement.

For multiple Delivery Locations under one School/date, print the School name and subordinate `Điểm giao: <Tên điểm giao>` on the subgroup's first row. One location prints School only. Hidden Location ID remains row-bound; ambiguous canonical labels block export. Protected filtering is best effort, never an identity requirement or Product blocker.

The retained black/white Times A4 specimen has 20 pt title, 16 pt headings/body/School and 14 pt Supplier; rows 32/34/44 pt with ≤44 pt cap; widths `26 / 39 / 7 / 11 / 25`. These are historical baseline constants, not approved final physical scale. The new acceptance gate requires ≥95% native print scale and ≥17 pt effective body without clipped fixture values or hashed quantities. Borders, column order, portrait composition and business semantics remain unchanged.
